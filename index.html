01 / DATA ENGINEERINGFeatured project
Salesforce → Python → Snowflake

Salesforce-to-Snowflake Incremental ETL Pipeline

A Python and Jupyter pipeline that synchronizes Account, Contact, and Opportunity into Snowflake ODS tables. Daily incremental loads use metadata-driven schemas, SystemModstamp watermarks, temporary staging, and ID-based MERGE. A separate monthly reconciliation compares IDs, recovers missing records, and preserves deleted records with soft-delete flags.

Inspect each stage

Execute setup and helper cells in order, then use the documented helper walkthrough to inspect DataFrame counts, datetime conversions, and schema mappings before loading. Review MERGE metrics and watermark history before advancing.

Reconcile monthly

Run the separate notebook once a month after hours with daily loads paused. Preview counts, retrieve missing records, and recheck deletion candidates before setting soft-delete flags. Both workflows have been validated with live data by the project owner; documentation covers visibility requirements, rollback, and recovery limits.

02 / PYTHON & FILESYSTEMSFeatured project
Scan → SQLite → Review → Cleanup

Duplicate File Scanner & Cleanup Toolkit

A Python filesystem auditing utility that identifies duplicate files by whole-file SHA-256 content hashes and stores scan results in SQLite. Scanning and cleanup are separate commands: preview changes and choose whether to retain the alphabetically first path or the most recently modified copy before moving or deleting duplicates.

Choose what to keep

Newest-file retention reads current filesystem modification times at nanosecond precision, with an alphabetical tie-breaker. Either policy works with quarantine moves or deletion; cleanup requires an explicit apply option.

Verify before cleanup

Recheck the retained copy and cleanup candidates against recorded content hashes. Read-only previews, collision-safe quarantine paths, and recorded move mappings support review and recovery. Automated tests use disposable directories; design notes document filesystem race and metadata-preservation limits.
